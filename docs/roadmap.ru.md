# Дорожная карта

Этап считается пройденным только после записи доказательств по его критериям приёмки.

1. Исследование и архитектура — в работе. Зафиксировать ветку, релиз и ревизии пакетов upstream; описать доказательства frankel и открытые вопросы.
2. Основа ARM64 — не начат. Закрепить Arch-совместимую AArch64-среду сборки и воспроизводимо собрать минимальный набор upstream-пакетов.
3. Мобильное меню Quickshell — исходный прототип есть, runtime-критерий не пройден. Загрузить плагин в закреплённой оболочке upstream, проверить поиск/запуск/сенсорное управление и записать портретный и альбомный режимы.
4. Интеграция мобильного сеанса — не начата. Определить интерфейсы input method, ориентации, рабочих пространств/жестов, питания и уведомлений без изменения поведения upstream для настольных устройств.
5. Bring-up Pixel 10 — только внешняя экспериментальная работа. Проверить актуальные исходники mainline/мейнтейнеров, загрузку и восстановление на точном устройстве frankel, затем проверять компоненты по одному.
6. Готовность к повседневному использованию — не начата. Нужны проверенные телефония и экстренный вызов, зарядка, аудио, suspend/resume, обновления безопасности, восстановление, температурное поведение и длительные испытания.

Этапы 2–4 могут идти независимо от наличия Pixel 10. Документации одной недостаточно для завершения этапа.
