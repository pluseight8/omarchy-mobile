# Supported devices

No device is currently supported.

Google Pixel 10 (frankel) is the first and only hardware target in this project. It is not supported for installation or daily use. The research report lists EXPERIMENTAL boot and device-tree work and marks all other hardware functions NOT TESTED. No other phone is in scope until the generic architecture and a verifiable Pixel 10 milestone exist.

Update this page only when a device has a documented boot path, reproducible image build, validated recovery procedure, and per-component hardware test record.
