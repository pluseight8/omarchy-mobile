# Поддерживаемые устройства

Поддерживаемых устройств пока нет.

Google Pixel 10 (frankel) — первая и единственная аппаратная цель проекта. Установка и ежедневное использование не поддерживаются. В отчёте об исследовании загрузка и Device Tree имеют статус EXPERIMENTAL, остальные аппаратные функции — NOT TESTED. Другие телефоны не рассматриваются, пока не готова общая архитектура и проверяемый этап для Pixel 10.

Обновляйте эту страницу только после документирования загрузки устройства, воспроизводимой сборки образа, проверенной процедуры восстановления и результатов испытаний каждого аппаратного компонента.
