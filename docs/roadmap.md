# Roadmap

Each milestone advances only when its acceptance evidence is recorded.

1. Research and architecture — in progress. Pin upstream branch, release, and package revisions; document frankel evidence and open questions.
2. ARM64 foundation — not started. Pin an Arch-compatible AArch64 build environment and build a minimal upstream package set reproducibly.
3. Quickshell mobile menu — source prototype present; runtime gate not passed. Load the plugin in the pinned upstream shell, verify search/launch/touch interaction, and capture portrait and landscape results.
4. Mobile session integration — not started. Define input method, orientation, workspace/gesture arbitration, power and notification interfaces without changing upstream behavior for desktop users.
5. Pixel 10 bring-up — experimental external work only. Confirm current mainline/maintainer sources, boot and recovery on exact frankel hardware, then test components one at a time.
6. Daily-use readiness — not started. Requires verified telephony and emergency calling, charging, audio, suspend/resume, security updates, recovery, thermal behavior, and extended hardware stability.

Milestones 2–4 can progress independently of Pixel 10 hardware. No milestone is complete based on documentation alone.
