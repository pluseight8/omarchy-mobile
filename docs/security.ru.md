# Модель безопасности

## Текущий код

В репозитории находится сторонний QML-плагин меню Omarchy и статические проверки Node. Плагин загружается в процесс оболочки Omarchy. Upstream прямо указывает, что сторонние плагины выполняются без песочницы и имеют те же пользовательские права на процессы и файлы. API библиотеки приложений ограничивает передаваемые меню возможности, но не изолирует код плагина.

Текущий launcher не выполняет shell-команды, не меняет настройки, не устанавливает пакеты, не обращается к firmware и не записывает разделы устройства. Поиск и запуск приложения делегируются существующему API Omarchy.

## Цепочка поставки

- Изучать изменения upstream и Quickshell перед обновлением compatibility.json.
- Закреплять GitHub Actions по неизменяемому commit SHA.
- Не добавлять firmware и бинарные blobs, пока не проверены источник, контрольная сумма, право распространения и привязка к устройству.
- Не считать factory image Android или случайный образ из интернета компонентом Omarchy Mobile.
- Не публиковать образ как установочный, пока не записаны точные входные данные и испытания устройства.

## Операции с устройством

В этом репозитории не реализованы разблокировка загрузчика, прошивка, выбор слота, AVB, повторная блокировка или запись разделов. На странице factory images Google описаны стирание данных при прошивке и anti-rollback изменение семейства Pixel 10 за май 2026 года. Для будущей операции нужен проверенный план восстановления для конкретной сборки и отдельное явное согласие владельца устройства.

## Сообщение об уязвимостях

О подозрениях на уязвимость следует сообщать сопровождающим приватно, не публикуя детали эксплуатации в issue. Контакт безопасности пока не настроен; до его добавления используйте приватную отправку security advisory GitHub для этого репозитория, если она доступна.
