# Omarchy Mobile

Omarchy Mobile — ранняя мобильная адаптация настоящего Quickshell Omarchy через интерфейс сторонних плагинов Omarchy. Это не Android ROM, не образ для Pixel и не система для повседневного использования.

Начальная версия репозитория содержит сенсорный плагин запуска приложений. Он использует контракт меню Omarchy, токены тем, поверхность оверлея и ограниченный API библиотеки приложений. Он не заменяет оболочку Omarchy и не копирует каталог приложений.

## Что реализовано

Корневой manifest объявляет сторонний плагин меню Omarchy. Его точка входа Quickshell открывает адаптивную сетку приложений в оформлении Omarchy и использует библиотеку приложений, предоставленную оболочкой. Карточки поддерживают запуск нажатием, детали при долгом нажатии и сенсорную прокрутку. Контрактные тесты Node проверяют manifest, жизненный цикл плагина, предположения об API upstream и сенсорные размеры.

Плагин требует работающую оболочку Quickshell upstream Omarchy. После установки и включения он вызывается через IPC плагинов upstream. Сам репозиторий пока не содержит пакет или установщик плагина.

Исходный код использует настоящий интерфейс плагинов upstream, но запуск в Quickshell ещё не проверялся. Workflow настроен на QML syntax lint и контрактные проверки исходников, однако для этой ветки он ещё не завершался. Он не проверяет runtime QML, снимки экрана, виртуальную клавиатуру, жесты за пределами этого меню или оборудование.

## Проверки разработки

Требуется Node.js версии 22 или новее. Из корня репозитория:

    npm test

Чтобы сравнить проверенную версию с локальной копией upstream Omarchy:

    OMARCHY_UPSTREAM=/path/to/omarchy npm run check:upstream

Скрипт находит изменения в контрактах плагинов, требующие проверки. Сам факт изменения не доказывает несовместимость. Запись о runtime-совместимости можно обновлять только после фактического запуска соответствующих тестов.

## Границы проекта

Upstream Omarchy остаётся источником истины для оболочки, CLI, плагинов, тем, настроек, миграций и обновлений. Мобильный интерфейс хранится в этом репозитории и использует документированные точки расширения. Поддержка платы Pixel 10 относится к отдельному слою устройства и не должна попадать в универсальный launcher.

В репозитории нет операций с загрузчиком, разделами или прошивкой. В текущем официальном уведомлении Google описано повышение anti-rollback для семейства Pixel 10 в обновлении за май 2026 года. Перед любыми будущими работами с устройством следует сверяться с официальной документацией восстановления.
